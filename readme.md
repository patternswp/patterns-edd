# Patterns Edd

> **Patterns EDD** is a modern and versatile block-based WordPress theme designed for digital product creators, online sellers, and entrepreneurs. Ideal for showcasing and selling eBooks, software, music, or design assets, it offers all the tools needed to build a sleek and effective online store.

## Description

Patterns EDD is a stylish and functional Full Site Editing (FSE) WordPress theme, perfect for building a professional online store for digital products like eBooks, software, music, and design assets. Designed to showcase digital offerings, product features, and customer feedback, this block-based theme empowers you to create a sleek and customizable eCommerce site. With its FSE capabilities, Patterns EDD enables seamless editing of headers, footers, layouts, and global styles directly within the WordPress Site Editor.

## Features

- **Full Site Editing (FSE):** Customize every aspect of your website using the WordPress block editor.
- **Elegant Design:** Perfect for digital stores, creators, and entrepreneurs selling online products.
- **Responsive Layouts:** Optimized for seamless display on all devices.
- **Pre-designed Templates:** Includes layouts for showcasing featured products, services, about, pricing, downloads, team, testimonials, contact page, and more.
- **Custom Block Patterns:** Simplify website creation with ready-to-use patterns.
- **SEO Optimized:** Built with best practices for improved search engine rankings.
- **High Performance:** Lightweight and optimized for fast loading.

## Getting Started

### Installation

- Clone the repository to your `/wp-content/themes/` directory:

  ```bash
  git clone https://github.com/patternswp/patterns-edd.git
  ```

- Or download and upload the theme files to `/wp-content/themes/patterns-edd`.

### Activate the Theme

Activate the theme via the WordPress admin dashboard under **Appearance > Themes**.

### Start Customization

With Full Site Editing support, you can customize the theme through the WordPress Site Editor by navigating to **Appearance > Editor**. Modify headers, footers, layouts, and global styles to suit your edd needs.

## Contributing

We welcome contributions to improve Patterns Edd! Here's how you can contribute:

1. **Fork the Repository**  
   Click the "Fork" button on the repository page.

2. **Clone your Fork**

   ```bash
   git clone https://github.com/your-username/patterns-edd.git
   ```

3. **Create a Feature Branch**

   ```bash
   git checkout -b my-new-feature
   ```

4. **Make Changes**  
   Implement your changes and stage them:

   ```bash
   git add .
   ```

5. **Commit Changes**  
   Commit with a descriptive message:

   ```bash
   git commit -m "Add feature for XYZ"
   ```

   ```bash
   git push origin my-new-feature
   ```

   Open a pull request with a clear title and description.
